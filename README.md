# hecho!

**やったことだけを記録する。** 未来の TODO ではなく、過去の DONE を積み上げるアプリ。

`hecho` はスペイン語で「done」。

**https://hecho-theta.vercel.app/**

iPhone / Android のホーム画面に追加すると、アプリとして起動します。

## なぜ作ったか

繰り返し発生する物事（風呂・洗濯・ゴミ出し・課題・自主学習）は、
忘れやすく、続けにくい。一方で一般的なタスク管理アプリは
「これからやること」を積むので、未消化が溜まるほど気が重くなる。

hecho! は逆をやる。**やったことだけを記録し、頻度が目で読み取れる形で可視化する。**
未来のレコードを持たないので、そもそも「積み残し」という状態が存在しない。

## 画面

横スクロールのタイムライン。行が習慣、列が日付。
やった日にその習慣の色のお団子が置かれ、やらなかった日は空欄のまま。

（スクリーンショットは後で追加）

## 技術構成

- Vite + React 19 + TypeScript
- Dexie (IndexedDB) — データは端末内で完結し、サーバーに送らない
- PWA（ホーム画面にインストールしてオフラインで起動）

## 開発

```bash
npm install
npm run dev
```
